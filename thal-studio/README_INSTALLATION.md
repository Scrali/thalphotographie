# Installation THAL Studio V0.4.0 FULL

## Installation via GitHub navigateur

1. Ouvre GitHub > dépôt `thalphotographie`.
2. Va dans le dossier `thal-studio`.
3. Upload tout le contenu de ce dossier `THAL_Studio_V0_4_0_FULL`.
4. Commit : `THAL Studio V0.4.0`.
5. OVH > Déployer Git.

## Installation via FileZilla

1. Renommer `/www/thal-studio` en `/www/thal-studio_backup`.
2. Envoyer ce dossier sous le nom `/www/thal-studio`.
3. Tester :
   - `/thal-studio/login.php`
   - `/thal-studio/devis.php`
   - `/thal-studio/quotes.php`
   - `/thal-studio/estimations.php`
   - `/thal-studio/estimation.php`

## Retour arrière

Supprimer le nouveau dossier `thal-studio`, puis renommer `thal-studio_backup` en `thal-studio`.
